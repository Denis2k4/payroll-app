Tài khoản Gmail người gửi

Sử dụng giao thức SMTP bảo mật của Google để gửi phiếu lương

💡 Hướng dẫn tạo mật khẩu ứng dụng Gmail:

  1. Đăng nhập tài khoản Google > vào mục Bảo mật (Security).
  2. Bật Xác minh 2 bước (2-Step Verification) nếu chưa bật.
  3. Vào mục Mật khẩu ứng dụng (App Passwords) > Tạo mới tên "HeheHR".
  4. Copy mã 16 ký tự vừa tạo dán vào ô mật khẩu ứng dụng bên trên.
🌐

Cấu hình Web Portal (Supabase Cloud)

Lưu trữ database, file PDF và cấp quyền đăng nhập cho nhân viên

💡 Hướng dẫn lấy URL & Service Role Key:

  1. Truy cập Supabase Dashboard > chọn dự án của bạn.
  2. Vào Project Settings (Biểu tượng bánh răng) > chọn mục API.
  3. Copy Project URL dán vào ô bên trên.
  4. Tại mục Project API keys, copy khóa service_role (secret) dán vào ô dưới.
Sẵn sàng. Hãy chọn file Excel để bắt đầu.
